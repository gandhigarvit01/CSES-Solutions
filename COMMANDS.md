# CSES Commands

## 1. Go to problem folder

cd Graph/ProblemName

Example:
cd Graph/MessageRoute

## 2. Compile

g++ filename.cpp -o filename

Example:
g++ messageroute.cpp -o messageroute

## 3. Run with input.txt

./filename.exe < input.txt

Example:
./messageroute.exe < input.txt

## 4. CSES Submission

Submit the .cpp file on CSES.

Only push to GitHub after AC.
